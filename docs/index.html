Installation

Load the published Flur.lua file, then call it to receive the library table. This example checks download, compilation and initialization separately so failures are easier to diagnose.

local LibraryURL = "https://raw.githubusercontent.com/MCUpload123/Fluriore-library/refs/heads/main/Flur.lua"

local ok, source = pcall(function()
    return game:HttpGet(LibraryURL)
end)
assert(ok, "FlurioreLib download failed: " .. tostring(source))

local chunk, compileError = loadstring(source)
assert(type(chunk) == "function", "FlurioreLib compile failed: " .. tostring(compileError))

local success, FlurioreLib = pcall(chunk)
assert(success, "FlurioreLib initialization failed: " .. tostring(FlurioreLib))
!

Review code before running it. A loader using loadstring executes the downloaded Lua source. Only use a source you trust and an executor/environment where you have permission to run scripts.

Quick start

Create a window, add a tab and section, then add controls. You can use this as a minimal starting point and customize it from there.

local LibraryURL = "https://raw.githubusercontent.com/MCUpload123/Fluriore-library/refs/heads/main/Flur.lua"
local FlurioreLib = loadstring(game:HttpGet(LibraryURL))()

local Window = FlurioreLib:MakeGui({
    NameHub = "My Hub",
    Description = "Made with FlurioreLib",
    Color = Color3.fromRGB(255, 0, 255),
    UIScale = 0.9,
    TextScale = 0.85,
})

local Tab = Window:CreateTab({Name = "Home", Icon = ""})
local Section = Tab:AddSection("General")

Section:AddParagraph({
    Title = "Welcome",
    Content = "This is your first FlurioreLib panel.",
})

Section:AddButton({
    Title = "Say hello",
    Content = "Prints a message when pressed.",
    Callback = function()
        print("Hello!")
    end,
})

Window API

Make a tab with Window:CreateTab, then place related controls inside a collapsible section. The window can be hidden, destroyed, made more transparent or assigned a different toggle key.

local Tab = Window:CreateTab({Name = "Main", Icon = ""})
local Section = Tab:AddSection("General")

Window:ToggleUI()
Window:DestroyGui()
Window:SetOpacity(0.15)
Window:SetToggleKey(Enum.KeyCode.RightShift)

Tab:SetBadge("2")
Tab:ClearBadge()

Section:Close()
Section:Open()
print(Section:IsOpen())
MethodPurpose
Window:CreateTab({Name, Icon})Creates a tab and returns its handle.
Window:ToggleUI()Shows or hides the window and returns the new visibility state.
Window:DestroyGui()Removes the library window.
Window:SetOpacity(number)Sets opacity from 0 (solid) to 0.95 (more transparent).
Window:SetToggleKey(KeyCode)Changes the key used to show or hide the window.
Tab:SetBadge(text) / Tab:ClearBadge()Sets or clears the tab badge.
Section:Open() / Section:Close()Opens or closes a section.
Section:IsOpen()Returns whether the section is open.

Section closing hides its children before shrinking the height; opening expands the section before showing its children again.

Themes

Theme colors are controlled by code. Provide a palette when creating the window or update selected values later. Every color value must be a Roblox Color3.

Window:SetTheme({
    Accent = Color3.fromRGB(80, 190, 255),
    Background = Color3.fromRGB(15, 18, 25),
    Surface = Color3.fromRGB(35, 40, 50),
    Text = Color3.fromRGB(245, 245, 245),
    MutedText = Color3.fromRGB(160, 170, 185),
    Border = Color3.fromRGB(65, 75, 90),
})

-- Change only the accent color
Window:SetAccent(Color3.fromRGB(120, 255, 160))

-- Read the active palette
local currentTheme = Window:GetTheme()
print(currentTheme.Accent)
Theme keyControls
AccentHighlights and active controls.
BackgroundMain window background.
SurfaceComponent surfaces.
TextPrimary text.
MutedTextDescriptions and secondary text.
BorderUI outlines.

When you call SetTheme, only supplied keys are changed. If no custom theme is provided at initialization, the built-in palette is used; Color sets the accent when Theme is omitted.

Scale

Text scale and overall UI scale can be changed independently. Calls return true when the requested value is accepted.

Window:SetTextScale(0.9)  -- range: 0.7 to 1.5
Window:SetUIScale(1.0)    -- range: 0.75 to 1.2

print(Window:GetTextScale())
print(Window:GetUIScale())

Default text scale: 0.85. Default UI scale: 0.9.

In-window search

The search field below the active tab title filters components by title and content. You can control the same filter from your script.

Window:SetSearch("speed") -- filter by title or content
Window:ClearSearch()      -- clear the filter

Keybinds

Change the window toggle key or register named keybinds with callbacks.

-- The default window toggle key is RightShift
Window:SetToggleKey(Enum.KeyCode.LeftControl)
print(Window:GetToggleKey())

Window:BindKey("fly", Enum.KeyCode.F, function()
    print("fly toggled from keybind")
end)

Window:UnbindKey("fly")
local binds = Window:GetBinds() -- map of id -> KeyCode

Named binds fire when the key is pressed and the input has not been processed by another GUI text box. They do not block the window toggle key.

Config API

Add a unique Flag to Toggle, Slider, Input, Dropdown or ColorPicker elements to include their values in config operations.

Section:AddToggle({
    Title = "Auto farm",
    Default = false,
    Flag = "auto_farm",
    Callback = function(enabled)
        print("auto_farm", enabled)
    end,
})

-- Save and load JSON files through executor filesystem APIs
local ok, pathOrError = Window:SaveConfig("FlurioreConfigs", "main")
local loaded, loadResult = Window:LoadConfig("FlurioreConfigs", "main")

-- In-memory config tools
local flags = Window:GetFlags()
Window:SetFlags({auto_farm = true})
local json = Window:ExportConfig()
Window:ImportConfig(json)

Available config methods

MethodWhat it does
SaveConfig(folder, name)Writes a JSON config file.
LoadConfig(folder, name)Reads a file and applies its values.
GetFlags() / SetFlags(table)Reads or applies registered values in memory.
ExportConfig() / ImportConfig(json)Exports or applies config as a JSON string.
RegisterFlag(flag, getFn, setFn)Registers a custom value using getter and setter functions.
ListConfigs(folder)Lists config filenames; requires listfiles.
DeleteConfig(folder, name)Deletes a config; requires delfile.
RenameConfig(folder, oldName, newName)Renames a config file.
i

Disk-based save/load needs executor filesystem APIs such as writefile and readfile. Folder and file helper availability can vary by executor. Methods return failure information when required APIs are missing.

Register a custom flag

Window:RegisterFlag("custom_stat", function()
    return myStat
end, function(value)
    myStat = value
end)

UI elements

Elements are created from a section. Use Callback to respond to user interaction and optional Flag values for configuration persistence.

Paragraph

local Info = Section:AddParagraph({
    Title = "Status",
    Content = "Initial status text.",
})

Info:Set({
    Title = "Updated status",
    Content = "This text can be updated at runtime.",
})

Button

Section:AddButton({
    Title = "Run",
    Content = "Runs a callback.",
    Icon = "rbxassetid://16932740082", -- optional
    Callback = function()
        print("Button pressed")
    end,
})

Toggle

local Toggle = Section:AddToggle({
    Title = "Enabled",
    Content = "Turn a feature on or off.",
    Default = false,
    Flag = "feature_enabled", -- optional
    Callback = function(enabled)
        print("Enabled:", enabled)
    end,
})

Toggle:Set(true) -- updates the control and calls Callback
print(Toggle.Value)

Slider

local Slider = Section:AddSlider({
    Title = "Power",
    Content = "Adjust the power value.",
    Min = 0,
    Max = 10,
    Default = 2.5,
    Increment = 0.25,
    Flag = "power", -- optional
    Callback = function(value)
        print("Power:", value)
    end,
})

Slider:Set(4.75)
print(Slider.Value)

Slider dragging supports mouse and touch input. The value field can be tapped to type a number. Increment controls rounding precision; the value is clamped to Min/Max.

Input

local TextInput = Section:AddInput({
    Title = "Player name",
    Content = "Enter a name.",
    Flag = "player_name", -- optional
    Callback = function(value)
        print("Input:", value)
    end,
})

TextInput:Set("Example")
print(TextInput.Value)

Dropdown

local Dropdown = Section:AddDropdown({
    Title = "Target",
    Content = "Choose an option.",
    Multi = false,
    Options = {"Alpha", "Bravo", "Charlie"},
    Default = "Alpha",
    Flag = "target", -- optional
    Callback = function(values)
        print(table.concat(values, ", "))
    end,
})

Dropdown:Set("Bravo")
Dropdown:AddOption("Delta")
Dropdown:Refresh({"One", "Two", "Three"}, "Two")
-- Dropdown:Clear() removes options and selection.

The dropdown's Value is a table of selected option strings, even when Multi = false. Options holds the available strings.

Color picker

local Picker = Section:AddColorPicker({
    Title = "Accent",
    Content = "Choose an accent color.",
    Default = Color3.fromRGB(255, 0, 255),
    Flag = "accent_color", -- optional
    Callback = function(color)
        Window:SetAccent(color)
    end,
})

Picker:Set(Color3.fromRGB(80, 200, 255))

Notifications

Show a notification from the library table. Time controls the animation duration; Delay is the auto-dismiss delay in seconds.

local Notice = FlurioreLib:MakeNotify({
    Title = "Saved",
    Description = "Settings",
    Content = "Your settings were saved.",
    Color = Color3.fromRGB(80, 200, 120),
    Time = 0.5,
    Delay = 4,
})

Global notification controls

FlurioreLib:SetNotifyPosition("TopRight")
-- Accepted positions: BottomRight, BottomLeft, TopRight, TopLeft

FlurioreLib:GetNotifyPosition()
FlurioreLib:SetNotifyMax(4) -- drop the oldest when the limit is reached
FlurioreLib:GetNotifyMax()
FlurioreLib:ClearNotifies()

Utility APIs

Window opacity

Window:SetOpacity(0.2) -- 0 = solid; higher = more transparent
print(Window:GetOpacity())

Opacity is clamped from 0 to 0.95.

Tab badge

local Tab = Window:CreateTab({Name = "Combat", Icon = ""})
Tab:SetBadge("3")
Tab:ClearBadge()

Section open / close

local Section = Tab:AddSection("Farm")
Section:Close()
Section:Open()
print(Section:IsOpen())

Config list helpers

local names = Window:ListConfigs("FlurioreConfigs") -- needs listfiles
Window:DeleteConfig("FlurioreConfigs", "main")     -- needs delfile
Window:RenameConfig("FlurioreConfigs", "main", "backup")

Notes & compatibility

  • FlurioreLib targets executor environments that expose game:HttpGet() and loadstring(); compatibility may vary by executor and version.
  • Disk config methods rely on supported filesystem functions such as writefile, readfile, and optionally makefolder, isfolder, listfiles or delfile.
  • UI descriptions wrap to their available width; slider precision comes from Increment, Min and Max.
  • Closing sections and minimizing the window hide content before resizing to reduce clipped or jumping layouts.
  • Executor behavior can vary, and not every executor configuration has been runtime-tested.
!

Use responsibly. Run scripts only where allowed and review downloaded source before execution.
