FlurioreLib

Compact UI library for script hubs: window, tabs, sections, elements, theme, config, search, and keybinds — one loadstring.

Raw source 
https://raw.githubusercontent.com/MCUpload123/Fluriore-library/refs/heads/main/Flur.lua

Installation

local FlurioreLib = loadstring(game:HttpGet(
  "https://raw.githubusercontent.com/MCUpload123/Fluriore-library/refs/heads/main/Flur.lua"
))()

local Window = FlurioreLib:MakeGui({
  NameHub = "My Hub",
  Description = "Built with FlurioreLib",
  Color = Color3.fromRGB(255, 0, 255),
  TextScale = 0.85,
  UIScale = 0.9,
})

Window

local Tab = Window:CreateTab({ Name = "Main", Icon = "" })
local Section = Tab:AddSection("General")

Window:ToggleUI()
Window:DestroyGui()
Window:SetOpacity(0.15)
Window:SetToggleKey(Enum.KeyCode.RightShift)

Tab:SetBadge("2")
Tab:ClearBadge()

Minimize hides content first, then shrinks height. Expand restores size before showing content again.

Theme & scale

Window:SetTheme({
  Accent = Color3.fromRGB(80, 190, 255),
  Background = Color3.fromRGB(15, 18, 25),
  Surface = Color3.fromRGB(35, 40, 50),
  Text = Color3.fromRGB(245, 245, 245),
  MutedText = Color3.fromRGB(160, 170, 185),
  Border = Color3.fromRGB(65, 75, 90),
})
Window:SetAccent(Color3.fromRGB(120, 255, 160))
print(Window:GetTheme().Accent)

Window:SetTextScale(0.9)  -- 0.7–1.5
Window:SetUIScale(1.0)    -- 0.75–1.2

Search

Window:SetSearch("farm")
Window:ClearSearch()

In-window search box under the tab title uses the same filter.

Keybinds

Window:BindKey("fly", Enum.KeyCode.F, function()
  print("fly")
end)
Window:UnbindKey("fly")
print(Window:GetBinds())

Config

Add Flag on Toggle, Slider, Input, Dropdown, ColorPicker.

Section:AddToggle({
  Title = "Auto farm",
  Default = false,
  Flag = "auto_farm",
  Callback = function(v) end,
})

Window:SaveConfig("FlurioreConfigs", "main")
Window:LoadConfig("FlurioreConfigs", "main")
Window:ListConfigs("FlurioreConfigs")
Window:DeleteConfig("FlurioreConfigs", "main")
Window:RenameConfig("FlurioreConfigs", "main", "backup")

local json = Window:ExportConfig()
Window:ImportConfig(json)

Notifications

FlurioreLib:SetNotifyPosition("TopRight") -- BottomRight, BottomLeft, TopRight, TopLeft
FlurioreLib:SetNotifyMax(4)
FlurioreLib:ClearNotifies()

FlurioreLib:MakeNotify({
  Title = "Saved",
  Description = "Config",
  Content = "Profile written.",
  Color = Color3.fromRGB(80, 200, 120),
  Time = 0.35,
  Delay = 4,
})

Elements

Paragraph / Button / Toggle / Slider / Input / Dropdown / ColorPicker

Section:AddParagraph({ Title = "Info", Content = "Text" })
Section:AddButton({ Title = "Run", Content = "Does a thing", Callback = function() end })
Section:AddToggle({ Title = "On", Content = "...", Default = false, Flag = "x", Callback = function(v) end })
Section:AddSlider({ Title = "Power", Min = 0, Max = 10, Default = 2, Increment = 0.25, Flag = "p", Callback = function(v) end })
Section:AddInput({ Title = "Name", Content = "...", Flag = "n", Callback = function(v) end })
Section:AddDropdown({ Title = "Mode", Options = {"A","B"}, Default = "A", Flag = "m", Callback = function(v) end })
Section:AddColorPicker({ Title = "Accent", Default = Color3.fromRGB(255,0,255), Flag = "c", Callback = function(c) Window:SetAccent(c) end })

Section API

Section:Open()
Section:Close()
print(Section:IsOpen())

Notes

  • Disk config needs executor writefile / readfile (and ideally listfiles / delfile / makefolder).
  • Default text scale is 0.85.
  • Review any loadstring source before running it.
